# 📸 Smart Gallery – WhatsApp Media Manager

An Android application that automatically organizes WhatsApp group images into separate galleries and manages media retention.

## 🚀 Features

- **Automatic Image Detection:** Detects newly received WhatsApp group images.
- **Group-wise Galleries:** Organizes images into separate galleries for different groups.
- **Group Management:** Select which WhatsApp groups you want to manage.
- **Custom Retention Periods:** Choose 5 minutes, 1 day, 7 days, 15 days, or 30 days.
- **Automatic Cleanup:** Deletes expired original media according to the selected retention period.
- **Permission Setup:** Guides users through the required Android storage permissions.

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Android SDK
